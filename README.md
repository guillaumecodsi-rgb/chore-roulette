# 🎡 Roulette des Tâches

Une application web fun et ludique pour assigner aléatoirement les tâches ménagères pendant les vacances en famille.

## Fonctionnalités

- 🏠 Liste de tâches ménagères avec emojis
- ➕ Ajout de tâches personnalisées (sauvegardées en Local Storage)
- 🗑️ Suppression des tâches personnalisées
- 👨‍👩‍👧‍👦 Gestion des participants (activer/désactiver)
- 🎡 Roulette animée avec effet de ralentissement
- 🎉 Confettis à l'annonce du résultat
- 📱 Responsive (mobile, tablette, desktop)
- 🇫🇷 Interface entièrement en français

## Installation

```bash
npm install
npm run dev
```

## Déploiement

L'application se déploie automatiquement sur GitHub Pages via GitHub Actions à chaque push sur `main`.

## Stack technique

- React 18 + TypeScript
- Vite
- Tailwind CSS
- canvas-confetti
